A language you can make your own.

Lingua brings a small, understandable programming language and a focused browser workspace together. Write an idea, run it, and keep exploring without setting up a development environment.

Small syntax. Real building blocks.

Variables, arithmetic, text, booleans, conditions, and loops cover the fundamentals. Functions, lexical closures, recursion, and arrays let those fundamentals become reusable programs. The language stays intentionally compact so its behavior is possible to understand.

fn double(number) {
  return number * 2;
}
let values = [2, 4, 6];
print(double(values[1]));

This program prints 8. No packages, project scaffolding, or hidden setup.

A workspace built for flow

Monaco brings line numbers, syntax colours, completion snippets, bracket matching, find, and undo to the editor. Run with Ctrl+Enter and read the result in the terminal. Local drafts preserve work in the same browser, while file import and export let you take it elsewhere.

The Explorer organizes saved programs into folders. When the server database is connected, programs can be created, opened, updated, and deleted.

Understand what you wrote

The optional Groq assistant opens with Ctrl+Alt+B. Ask for an explanation, help locating a mistake, or a different approach. Your current code is sent only when you submit a question. Responses are suggestions: the assistant cannot change files or execute programs, and its answers should be checked.

Built from the language outward

Lingua uses its own tokenizer, parser, and interpreter written in JavaScript. Programs execute in the browser rather than being passed to JavaScript eval. Execution limits bound loops, recursion, and output. Express handles saved-program APIs, and MongoDB stores program records.

The interface combines HTML, CSS, Monaco, and a React-powered ShapeWaves home page. The source is available to explore, study, and improve.

Where it stands

This is a working language playground under active development, not a replacement for a general-purpose production language. Saved programs currently share a server database; there are no private accounts or live collaborative sessions. The AI assistant requires a server-side Groq key. Those boundaries are explicit so you know what your workspace can do today.
