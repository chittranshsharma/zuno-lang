# Zuno Language Tools

Open a `.zuno` file in VS Code or Cursor. Use **Zuno: Run current file** or **Zuno: Check current file** from the command palette. The extension bundles the Zuno interpreter and requires Node.js 20 or newer on PATH. Configure `zuno.nodePath` if Node is installed elsewhere.

Includes syntax highlighting, bracket matching and line comments. This is a local extension, not a published Marketplace listing. Browser UI apps still run in the Zuno playground; the local CLI runs console programs and file modules.
