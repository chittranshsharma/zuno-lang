# Zuno Language Tools

Download the VSIX from the Zuno 0.4.0 release and use Extensions → … → Install from VSIX in VS Code or Cursor. Node.js 20+ is required; set zuno.nodePath if Node is not on PATH.

Open a .zuno file for Zuno: Run current file or Zuno: Check current file. Open a project folder for Zuno: Run project or Zuno: Check project. Project commands use the entry field in zuno.json. Errors appear in the Problems panel at the original file and line. The extension bundles the runtime, so installing the global zuno command is optional.

Includes syntax highlighting, bracket matching and line comments. This is a local extension, not a published Marketplace listing. Browser UI apps still run in the Zuno playground; the local CLI runs console programs and file modules.
