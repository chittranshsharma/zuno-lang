Lingua / AI
A second perspective.
Powered by Groq. Submitting sends your current code and question to Groq. Suggestions never change files automatically.


Connect Groq Setup guide
  1. Create a Groq API key ↗
  2. In the Lingua project folder, create a file named .env alongside server.js and package.json.
  3. Add this line, replacing the placeholder:
    GROQ_API_KEY=your_key_here
  4. Restart the server with npm start, then ask your question.
For hosted sites, add GROQ_API_KEY in your hosting provider’s environment variables. This is server-owner setup; visitors cannot configure a shared server here. Keep the key out of chat, browser code, and Git.
