Beginner guide

Learn Lingua, one step at a time

You only need two commands to get started: let stores a value and print shows it. Try each example in the playground.

Playground examples

The example menu includes five programs, covering greetings, maths, conditions, loops, functions, and arrays. Hello World prints World. Simple Maths prints 8 and 15. Power and Brackets prints 25 and 1. Choose one, press Run, then change a value and run it again.

Step 1: Print something

Type this in the code box and click Run.

print("Hello!");

Output:

Hello!

Text goes inside double quotes. The semicolon tells Lingua where the statement ends.

Step 2: Store a value

A variable is a name for a value. Here, name stores the text "Avi". Spaces around = are optional, so let name="Avi"; works too.

let name = "Avi";
print(name);

Output:

Avi

When you write print(name);, Lingua looks up the value stored in name. print("name"); prints the word name because quotes mean plain text.

Step 3: Work with numbers

Numbers do not need quotes. You can store them and use them in calculations.

let marks = 40;
print(marks + 10);

Output:

50

You can use + to add, - to subtract, * to multiply, / to divide, ** for powers, and % for the remainder.

Step 4: Use two variables

Variables can be used together in a calculation.

let price = 20;
let quantity = 3;
print(price * quantity);

Output:

60

Try changing either number and running the program again.

Quick syntax guide

Show textprint("Hi");
Save a numberlet score = 10;
Save textlet city = "Delhi";
Show a variableprint(score);
Do mathsprint(score + 5);

End each statement with a semicolon. Empty lines are fine. A variable name can contain letters, numbers, and underscores, but it must start with a letter or underscore.

Common mistakes

  • Missing semicolon: print("Hi") needs ; at the end.
  • Missing quotes: print(Hello); looks for a variable named Hello. Use print("Hello"); for text.
  • Unknown variable: create it with let before printing it.

The output box will show a line number when something goes wrong, so you know where to look.

Step 5: Powers and brackets

Choose Power and Brackets from the example menu, or paste this program:

let answer = (2 + 3) ** 2;
print(answer);
print(10 % 3);

Output:

25
1

Brackets run first. Then powers, multiplication, division and remainder run before addition and subtraction.

What else can I do?

The playground can export your code as a .lingua file and import it again later. You can give that file to a friend so they can open it in their playground.

When MongoDB is running, open Save or edit program in the Explorer. Give your program a title and a folder such as College/Maths, then click Save new. Click a file in the Explorer to load it; use Update selected or Delete selected for changes. The highlighted file is the one you selected, and the editor tells you when its code has unsaved changes. Saved programs are shared in one database for this course demo, so anyone using the same server can see and change them.

Conditions and loops are supported. Functions and arrays are also supported. The language currently supports let, print, numbers, double-quoted text, maths and brackets.

Conditions and loops

Use if and else to choose a block. Use while to repeat a block. Braces group the statements. Change a variable with assignment to make progress toward ending a loop.

let n = 1;
while (n <= 5) {
  if (n % 2 == 0) {
    print(n);
  }
  n = n + 1;
}

This prints 2 and 4. Infinite loops stop with an execution-limit error.
