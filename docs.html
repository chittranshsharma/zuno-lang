A dialect you can remember

vibe declares something you can change; lock keeps the binding fixed; cook defines a function; yeet returns a result; yap prints; fr means true; cap means false. Now bet starts a condition, nah handles the alternative, grind repeats while a condition holds, and each walks a collection. Use and, or, and not for readable logic. Conventional keywords still work. The dialect words are reserved; use quoted dictionary keys when a field shares a keyword.

vibe energy = 3;
grind energy > 0 {
  bet energy == 1 {
    yap("Last round");
  } nah {
    yap("Still cooking");
  }
  energy = energy - 1;
}
each item in ["build", "try", "repeat"] {
  yap(item);
}
bet fr and not cap { yap("Ready"); }

Parentheses around if/bet and while/grind conditions are optional. Semicolons still end simple statements. No slang memorization is required: if, else, while, for, let, const, fn, return, and print remain available.

Build an interactive app

Select Clicker app, Converter app, or Quiz app in the studio and press Run program, or choose Preview app. Your app appears beneath the workspace. Zuno functions become event handlers; their captured variables keep state between clicks. Run again to reset the app. Hide unloads the preview.

import ui as app;
vibe clicks = 0;
app.title("Click check");
app.label("score", "Clicks: 0");
cook click() {
  clicks = clicks + 1;
  bet clicks >= 10 {
    app.set("score", "Double digits. You cooked: " + text(clicks));
  } nah {
    app.set("score", "Clicks: " + text(clicks));
  }
}
cook reset() {
  clicks = 0;
  app.set("score", "Clicks: 0");
}
app.button("+1", click);
app.button("Reset", reset);

The ui module

import ui as app; is available in the browser preview. app.title(text) adds a heading. app.label(id, text) adds a text label. app.input(id, caption) adds a labeled text input; app.value(id) reads it. app.set(id, text) updates a label or input. app.button(caption, callback) connects a zero-argument Zuno function. app.clear() removes widgets, but preserves language variables. Widget IDs must be unique. Values and captions must be text.

Build counters, calculators, converters, quizzes, trackers, and small input-driven tools. Apps cannot use HTML, CSS, arbitrary JavaScript, network requests, device APIs, or persistent storage yet. The sandbox blocks network access. Each event receives a fresh 100,000-step budget. The preview allows up to 200 top-level widgets and 10,000 characters per UI text value. Console output is separate from UI labels; use app.set for visible app results. ui is unavailable in the CLI.

Start with an idea

Use yap to show a value. Statements end with semicolons; braces group blocks. Numbers, double-quoted text, booleans, arrays, and functions are supported.

vibe name = "world";
yap("Hello, " + name);

Variables and constants

vibe creates a mutable binding. lock prevents reassignment of the binding; an array held by lock can still be mutated. Nested blocks have their own scope. Names are case-sensitive.

vibe score = 10;
score = score + 5;
lock target = 20;
yap(score >= target);

Choose your voice

Playful and conventional keywords share one runtime. vibe = let; lock = const; cook = func = fn; yap = say = print; yeet = return; fr = true; cap = false. These words are reserved. Line comments start with //.

lock ready = fr;
if (ready && !cap) {
  yap("Let us cook");
}

Expressions and maths

Arithmetic: +, -, *, /, %, **. Comparison: ==, !=, <, <=, >, >=. Logic: &&, ||, !. Powers bind before unary minus; multiplication binds before addition. Logical expressions short-circuit. Division by zero and non-finite results are errors.

yap((2 + 3) ** 2);
yap(sqrt(81));
yap(round(8.6));
yap(floor(8.6));
yap(ceil(8.1));
yap(abs(-12));

Conditions and repetition

if/else chooses a block. while repeats while its condition is truthy. for item in values iterates an array or text. range excludes its end and supports at most 10,000 items.

vibe total = 0;
for n in range(1, 6) {
  total = total + n;
}
if (total == 15) {
  yap("Correct");
} else {
  yap("Try again");
}

Functions, closures, recursion

Functions capture their surrounding scope. Pass exactly the declared number of arguments. A function can return another function. A missing return produces false. Calls may also stand alone as statements.

cook multiplier(factor) {
  cook apply(value) {
    yeet value * factor;
  }
  yeet apply;
}
lock triple = multiplier(3);
yap(triple(14));

Arrays that do useful work

Indexing starts at zero. Out-of-bounds reads are errors. push and pop mutate arrays; sort, reverse, and slice return copies. sort accepts numeric arrays. push currently accepts primitive values and caps arrays at 10,000 items. Nested arrays and indexed assignment are supported.

vibe scores = [82, 94, 71, 88];
push(scores, 95);
lock average = sum(scores) / len(scores);
yap("Average: " + text(round(average)));
yap("Highest: " + text(max(scores)));
yap("Sorted: " + join(sort(scores), ", "));
assert(len(scores) == 5);

Text processing

Use trim, split, join, upper, lower, contains, replace, and slice. replace changes every literal occurrence. Text indexes refer to UTF-16 code units; for iteration follows Unicode code points. Text produced by replace and join is limited to 100,000 characters.

lock words = split(trim("code creates possibilities"), " ");
yap("Words: " + text(len(words)));
for word in words {
  yap(upper(word));
}

Conversions and assertions

number converts numeric text and rejects non-finite results. text converts primitive values. assert stops the program with a useful error when its condition is false.

lock price = number("19.5");
lock quantity = 3;
lock total = price * quantity;
assert(total > 0, "Total must be positive");
yap("Total: " + text(total));

Run outside the browser

Download the runtime archive and editor extension from the Zuno 0.4.0 release. Install the archive with npm install --global ./zuno-runtime-0.4.0.tgz. Node.js 20+ is required. Use zuno init my-app, enter that folder, then use zuno run or zuno check. The entry field in zuno.json selects src/main.zuno by default. VS Code and Cursor can install the VSIX through Extensions → … → Install from VSIX. Run/Check project commands support clickable errors in the Problems panel. You can also run node cli.js examples/scoreboard.zuno directly. Use node cli.js --check examples/scoreboard.zuno to parse without executing. The CLI uses the same engine as the playground.

Your workspace

The + in the tab bar creates a new file. × closes a file, asking before discarding unsaved work. A dot marks unsaved changes. Ctrl+Alt+N creates a file; Ctrl+Shift+T reopens a recently closed one. Command search also provides Close and Reopen. After the last tab closes, only New file remains in the editor. Unsaved tabs offer Save, Don’t save, and Cancel. Save writes a local file or saves to your account; a cancelled or failed save keeps the tab open. Examples are available through the Examples button.

Open files and text restore after refresh from browser storage, with separate guest and account workspaces. Sign-out returns to guest tabs. Recovery is local to this browser, not a cloud backup; local drafts remain in site storage on shared computers. Up to 40 tabs are supported. Undo history survives tab switching, but not refresh.

Open examples and saved files in tabs. Ctrl+Enter runs code. Ctrl+Shift+P opens commands. Resize the editor and Explorer with drag handles or keyboard-accessible sliders. Syntax markers never execute your code. Runtime errors appear after Run. Private saved files require an account; optional autosave updates existing saved records. Hosting is deferred, so cross-device access requires your own deployed server.

AI with review built in

Ctrl+Alt+B opens the Groq assistant with GPT-OSS 120B. Paste your own key, then choose Use key. Ask selection attaches highlighted code. Chat streams Markdown, supports follow-ups, and can be stopped. Suggest edit opens a diff; Accept is undoable, Reject leaves the source untouched, and stale suggestions cannot overwrite newer edits. Keys and conversation history live only in page memory.

Modules, dictionaries, and classes

Dictionaries use quoted string keys. Access with profile.score or profile["score"]; assign with the same syntax. Missing keys are errors. The dict standard module provides keys, values, has, and remove. Dictionaries are backed by isolated maps: prototype names are ordinary keys.

import math as m;
import dict as d;
module scoring {
  cook double(value) { yeet value * 2; }
}
import scoring as scores;
class Counter {
  cook init(start) { this.count = start; }
  cook next() {
    this.count = this.count + 1;
    yeet this.count;
  }
}
vibe counter = Counter(4);
vibe profile = {"name": "Avi", "score": scores.double(21)};
profile.score = profile.score + counter.next();
yap(profile.name);
yap(profile.score);
yap(join(d.keys(profile), ", "));
yap(m.sqrt(81));

Class bodies contain named methods. init is optional and receives constructor arguments. Instantiate with Counter(4), without new. Methods bind this even when stored in another variable. Fields are created by assignment. Inheritance, static members, and access modifiers are not implemented.

Declare module name { ... } before import name as alias;. All local declarations are exported; nested block locals remain private. Modules run once at declaration and imported bindings cannot be reassigned. Standard modules are math, strings, arrays, dict, and testing. Examples: m.sqrt(81), arrays.range(4), strings.upper("hi"), testing.assert(fr).

File modules in the CLI

Write import "./helpers.zuno" as helpers; on its own line. The CLI loads module files once in dependency order and rejects cycles, imports outside the project root, and more than 100 files including the entry. The closest zuno.json defines the project root; without one, the entry directory is the root. Errors refer to original file positions. Try node cli.js examples/modules/main.zuno for a complete two-file program. File imports are a CLI feature; the browser uses inline module blocks and the standard library. Imported files export their top-level declarations. Their output runs once on load.

Know the boundaries

This is an interpreted language for learning, algorithms, text processing, and small calculations. It is not yet a Python or C++ replacement. No package manager, inheritance, native compilation, networking, filesystem access from programs, or async execution. Source is capped at 100,000 characters; saved/imported programs at 5,000. Runs stop at 100,000 evaluation steps, 1,000 output lines, 200 parser nesting levels, or 100 nested function calls.
